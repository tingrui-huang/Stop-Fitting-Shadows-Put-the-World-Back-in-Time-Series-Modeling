01 / 结论不是模型强，是题目自带答案

S1 是六个 sanity 消融里最激进的一个：不给时间序列、不给 ground-truth 文章、不给干扰文章池， 只把题干和 A/B/C/D 四个选项喂进去。按设计它应该掉到接近随机的 0.25。

它拿到了 0.96，是十个条件里的最高分。Sonnet-5 上跑同一套是 0.94，同样高于它自己的 C0/C1（0.88）。 两个模型家族都复现，所以这是 benchmark 的性质，不是某个模型的怪癖。

最要命的一个数

「S1 和带证据条件两边都错」的题数是 0（C0/C1/C2/S2/S3/S4 全部如此）。 也就是说，这 50 道题里没有一道是必须读了证据才能做对的。 选项集本身就是标签的完整信息源。

模型自己也知道。50 条推理轨迹里有 39 条明确写了「prompt 里没有给我文章和数据，无法核实」—— 这 39 条里 37 条照样答对了。它宣布自己没有依据，然后答对。

02 / 机制三层缺陷，深度递增

我把 50 条轨迹逐条读了推理结论，按决定性的那一步打了互斥标签。 39 题（78%）是在完全不动用任何金融知识、只利用选项集内部结构的情况下做对的。

这 39 题不是同一个毛病。它们分成三层，修法完全不同，而且只有第一层能靠"把题出好一点"解决。

第 1 层

干扰项太弱

18 题 · 36%

干扰项在字面上就荒谬，不需要看任何证据，靠金融常识 101 就能划掉。 典型措辞是绝对化的：permanently、undoubtedly、complete rejection。

A. 影响 Nike 库存的供应链问题是永久性的，因此股价回到前高极不可能。
B. P/E 之类的估值指标不重要、可以忽略。
D. 股价此前跌得太狠，不会有任何买家出现。 instance 15 · 剩下的 C 是唯一一句正常人写的话

这一层是真正的出题质量问题。模型的原话就是「A、B、D 含极端或金融上说不通的主张， C 是唯一一个逻辑与金融都站得住的」——它根本没在做题，在做文本体检。

修法：重写干扰项就能解决

第 2 层

形式泄漏真值

9 题 · 18%

真陈述系统性地比假陈述更具体。按题干极性拆开数，每个选项携带的数字个数是：

选项表层特征 · 随题干极性完美翻转
题型选项数字/选项绝对化词/选项
问 correct金标（真）1.700.00
干扰项（假）0.480.12
问 incorrect金标（假）0.470.12
干扰项（真）1.470.00

三倍的差距，而且随极性完美翻转，没有一个混合情形。 「真陈述带具体数字，假陈述说空话」这条规则是构造时无意烧进去的。

我拿它写了个不看时间序列、不看新闻、不懂金融的单特征 regex 求解器（数字最多 = 真陈述）： 50 题对 29 题，0.58，规则无歧义时 0.71。随机是 0.25。

模型把这条规律直接说出来了：

「B 是唯一给出具体可量化细节的选项……这种程度的具体性通常就标志着它是对图表和新闻的正确描述。」 instance 353 · 它学到的不是金融，是我们的出题习惯

注意这一层不是难度问题。你可以把每个选项都写得极其复杂， 只要真的那个仍然更具体，这条相关性原封不动。它是池子层面的统计约束—— 单看任何一道题都发现不了，必须在整个题库上统计"表层形式"与"真值"的相关性并把它压到零。

修法：改单题没用，要在题库层面做统计约束

第 3 层

题型泄漏真值

12 题 · 24%

Which statement is incorrect? 这个格式在定义上要求： 三个干扰项必须是关于同一事件的真陈述，只有金标是假的。

也就是说，我们白送给模型三条保真的事实陈述。 那不是"简单的选项"，那是一个微型证据包。模型只要做交叉比对就能定位那条假的。

「C 声称市场认为盈利预期非常有利，这与 D 给出的 EPS 同比下降 31.09% 的数据直接矛盾， 因此 C 是错的。」 instance 288 · 模型把干扰项当证据文本读了——而且读对了，因为格式保证 D 是真的

现在设想我们把 A、B、C、D 每一条都写得无比精深复杂。三条仍然是真的，金标仍然是唯一那条假的， 交叉比对仍然定位得到它。这条通道随选项难度增加而增强，不是减弱。

这一层最危险，因为它伪装成高质量题目：干扰项越真实、越具体、越专业，泄漏越严重。 我们越用力出好题，这个洞越大。

修法：这个题型要退役

剩下 11 题不属于这三层：10 题靠通用金融机制推出来（「可转债公告 → 稀释担忧 → 股价跌」、 「Zacks Rank 3 是 Hold 不是 underperform」），1 题模型明说是随手占位。 S1 仅有的两个错误全部落在这 11 题里。

跨选项矛盾 12 题全部来自「问 incorrect」，33 道「问 correct」里一道都没有。 具体性启发 9 题全部来自「问 correct」，17 道「问 incorrect」里一道都没有。 每种题型有它自己的专属漏洞，而漏洞是格式给的。

这也顺带解释了一个之前没想通的现象：为什么 C2 的准确率（0.939）反而比 C1（0.920）高。 C2 遮掉的是证据里的时间信息，但选项集这个"影子证据包"一点没动—— 遮蔽作用在了唯一没被使用的通道上。

04 / 别走错路问题不是"题太简单"

这是最容易得出的错误诊断，它的修法是"出难一点"，而这条路只够到 18/50。

难度和证据依赖是两根正交的轴。我们手上已经有一个把难度拉上去的现成对照——C3： 它明显更难（0.78），但一点也没有更依赖证据，拿掉全部证据的 S1 反而比它高 18 个点。 C3 的难度来自干扰池噪声，不是来自"必须读时间序列才能答"。难度上去了，测的东西没变。

真正该盯的量不是准确率，是差值 Δ = 有证据 − 无证据。现在这个差是 −0.04。 题出得再难，只要 Δ 还是负的，我们什么也没多测到。

该换的判定标准

一道题有资格留下，当且仅当拿掉证据它就死。可操作化成一句话： 把 A 题的选项配上 B 题的时间序列和新闻，答案必须变。

这个判据和难度完全无关——一道很简单但证据依赖的题（「窗口内最高价出现在哪天」）照样合格， 一道很难但证据无关的题一律不合格。按这个标准，现在这 50 道一道都不合格。

05 / 下一步建议顺序

  1. 先跑 evidence-swap 测试。拿现成的 50 组数据交叉配对，A 题选项配 B 题证据， 跑一轮就能给出每道题的证据依赖度，直接产出"该重写 / 该退役"的清单。比重建题库便宜得多， 而且能把上面读出来的三层，落成每条通道各贡献多少个百分点。
  2. 论文里把 S1 当地板报告。只认高于 S1 的部分。按这个算 C0/C1 = −0.04、C3 = −0.18。 数字很难看，但它比原来的叙事更强：不是"模型不会做时间推理"， 而是这类 benchmark 的选项集本身就是影子——正好是标题里那个词。
  3. 退役 which is incorrect 题型。第 3 层修不掉，只能不用。 17 道题受影响。
  4. 换指标：看引用对不对，不看选对哪个字母。evidence_articles 字段我们已经在收了， 而且 S1 里它 50/50 全是空的——这个信号是干净的。
